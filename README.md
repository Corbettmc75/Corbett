# Corbett

A full-screen phone app for talking with an AI version of Corbett, in his own voice, made from his own stories.

- `index.html` is the app: tap the green button to call, red to hang up.
- `photo.jpg` is the still picture of Corbett (also the Home Screen icon).
- `listen.mp4` loops while it's listening; `talk.mp4` plays while it's talking.

If a clip is missing, the photo shows instead.
